# Code of Conduct

This is a technical project. The rules are short.

1. Be respectful. Disagree with ideas, not with people. No insults,
   harassment, threats or personal attacks, in any channel of the project.
2. Keep it about the work. Issues and pull requests are for the software:
   bugs, designs, code and documentation. Politics, and anything else
   unrelated to the project, belong elsewhere.
3. Be precise and honest. Report what you saw, with the output that shows
   it. Say what you tested. Do not claim more than you verified.
4. Respect people's time. Read the documentation and search the issues
   before opening one; follow the templates; keep changes focused.
5. Respect privacy. Never publish someone else's private information.

The maintainer decides what is in and out of scope, and may edit, close
or remove anything that breaks these rules, and block repeat offenders.
Report a problem privately through the maintainer's GitHub profile, or
through the repository's Security tab if it concerns security.
